# AVADEV Shopify Order Sync

Addon Odoo que sincroniza pedidos de Shopify hacia una tienda espejo mediante OAuth, webhooks y Admin API.

Código preparado para evaluación de la prueba técnica **Natulim**.

## Dependencias

- Odoo (`base`, `mail`)
- Python: `requests`

## Instalación

1. Copia la carpeta `avadev_shopify_sync` al path de addons de Odoo.
2. Actualiza la lista de aplicaciones.
3. Instala **AVADEV Shopify Order Sync**.
4. Configura la cuenta Shopify (credenciales OAuth / webhooks) desde el menú del módulo.
